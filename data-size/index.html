bit・byte・KB・MB・GBを
触って理解する

bitは0か1を表す最小単位。8個集まると1 byteになります。そこからKB、MB、GBへどう大きくなるのか、実際に変換しながら確認します。

8 bit = 1 byte

8個のbitをタップして0/1を切り替えてみてください。値が何であっても、この8個のまとまり自体が1 byteです。

← この8 bitで 1 byte →
bit数8 bit
10進数の値0
16進数00

単位はだんだん大きくなる

一般的なストレージ表記では1000倍ごとにKB → MB → GB → TBと大きくなります。

容量を変換してみる

1000基準のKB/MB/GBと、1024基準のKiB/MiB/GiBを切り替えて確認できます。

SI表記：1 KB = 1,000 B。SSDや通信速度などでよく使われます。
bit8,000,000 bit
byte1,000,000 B
KB1,000 KB
MB1 MB

1000と1024、どっちが正しい？

KB / MB / GB国際単位系では1000倍。1 KB = 1000 B、1 MB = 1000 KB。ストレージ容量や通信などで広く使われます。
KiB / MiB / GiB2進数に合わせた1024倍。1 KiB = 1024 B、1 MiB = 1024 KiB。OSやメモリ周辺で見かけます。

昔からコンピュータ分野ではKBを1024 byteの意味で使うことも多く、今でも表示が混在します。厳密に区別するときは1000系をKB、1024系をKiBと書きます。
