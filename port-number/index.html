IPアドレスが「どのコンピュータか」を表すなら、ポート番号は「その中のどのアプリに届けるか」を表します。宛先IPと宛先ポートをセットで見ると通信先がはっきりします。

IPでPC、ポートでアプリを選ぶ

サービスを選ぶと宛先ポートが変わります。「次へ」「自動で見る」で通信先が決まる順番を追ってください。

ポート番号は16 bit

ポート番号は 0〜65535 の範囲です。これは16 bitで表せる 2¹⁶ = 65536通り に対応します。IPアドレスだけでは同じPCのWeb、SSH、DNSなどを区別できないため、ポート番号で届け先のアプリやサービスを区別します。

0〜1023Well-known ports。HTTP 80、HTTPS 443、DNS 53、SSH 22など。
1024〜49151Registered ports。アプリや製品が登録して利用する範囲。
49152〜65535Dynamic / Private ports。クライアント側の一時的な送信元ポートなどで使われます。

よく見るポート

22 / TCP — SSHリモートログインや安全なシェル接続。
53 / UDP・TCP — DNS名前解決。通常の問い合わせはUDPが多く、TCPも使います。
80 / TCP — HTTP暗号化されていないWeb通信。
443 / TCP — HTTPSTLSで保護されたWeb通信。HTTP/3ではUDP 443も使います。
3389 / TCP・UDP — RDPWindowsのリモートデスクトップ。
25 / TCP — SMTPメールサーバー間のメール配送など。

送信元ポートもある

通信には宛先ポートだけでなく送信元ポートもあります。たとえばブラウザがHTTPSへ接続するとき、宛先は443でも、クライアント側は53024のような一時的なポートを使えます。返事はその送信元ポートへ戻るので、同じPCで複数の通信を同時に区別できます。

「443番ポートのPC」という意味ではありません。正しくは「あるIPアドレスのPC上で、443番ポートを使って待ち受けているサービス」です。
