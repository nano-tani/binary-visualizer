ポート番号は「そのコンピュータのどのサービスか」

ポート番号とは何かを初心者向けに解説。IPアドレスとの違い、HTTP 80・HTTPS 443・DNS 53など代表ポート、TCP/UDPの関係を触って学べます。

ポート番号の役割

TCPとUDPでは、通信のエンドポイントを区別するため16 bitのポート番号を使います。範囲は0〜65535です。

代表的な番号

IANAのService Name and Transport Protocol Port Number Registryには、HTTP 80、HTTPS 443、DNS 53などの割り当てが登録されています。実際のアプリは別ポートを使うこともできます。

TCPとUDPは別

同じ番号でもTCPの53番とUDPの53番は別のトランスポート上のポートです。DNSは用途に応じてUDPとTCPの両方を使います。

COMMON MISUNDERSTANDINGS

よくある勘違い

「443番なら必ず安全」443はHTTPSで一般的なポートですが、番号そのものが通信を安全にするわけではありません。
「サーバー側だけにポートがある」クライアント側も通常は一時的な送信元ポートを使います。
