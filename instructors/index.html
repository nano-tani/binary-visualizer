FOR INSTRUCTORS

「このURLを使おう」と判断できる情報を、先に。

受講者向けの分かりやすさだけでなく、講師が前提知識・到達目標・簡略化範囲・参考仕様を確認できる教材として設計しています。

新人研修ログイン不要印刷対応投影モード
60 MINUTES

非IT新人向け 60分プラン

最初から細部を教えず、Web通信までの地図を作る構成です。

1
2進数 8分0/1 = ON/OFF。計算暗記にしない。
2
IP + DNS 15分通信相手を指定する番号と、名前から調べる仕組み。
3
Port + TCP/UDP 15分届け先サービスと、届け方の違い。
4
HTTP/HTTPS 15分今までの知識を一本のWeb通信図につなげる。
5
説明させる 7分受講者同士で「URLから画面が出るまで」を自分の言葉で説明。
6ページ最短コースを受講者として開く →
90 MINUTES

ネットワーク新人向け 90分プラン

前半: IP / CIDR / DHCPアドレスと設定がどう決まるか。CIDRは計算より境界から。
中盤: ARP / DNS / Port同一LAN・名前解決・サービス識別をつなげる。
後半: TCP/UDP / handshake配送特性と接続確立。TCP切断は時間があれば発展。
まとめ: HTTP/HTTPS「結局Webアクセスで全部どう使われる？」へ戻す。
WHAT EACH LESSON PROVIDES

各教材で確認できること

到達目標冒頭の「このページで分かればOK」で学習範囲を限定。
前提知識と橋渡し前の知識が今回どこで使われるかを明示。
よくある誤解講師が補足すべきポイントを先回りして表示。
仕様・参考資料RFC、IANA、OWASP等へのリンクと簡略化範囲を掲載。
投影モード各ページの「講師向けメモ」から起動。ヘッダー等を隠して画面共有しやすくします。
印刷ブラウザの印刷で操作ボタンを除いた説明教材として出力できます。
ASSESSMENT

理解チェックの扱い

各ページの2問チェックは成績評価ではなく自己確認です。「分かった」記録もlocalStorageにのみ保存され、サーバーや講師へ送信されません。正式な研修評価が必要な場合は、口頭説明・LMSの小テスト・実務演習などを別途組み合わせてください。

おすすめの確認方法

  • 「DNSとは？」の用語暗記ではなく「URLを入力した後、なぜDNSが必要？」と説明させる
  • TCP/UDPではデータ消失シミュレーションを見せ、「何が違った？」を言葉にさせる
  • HTTP/HTTPSの最後に、6つの仕組みを順番ではなく役割で説明させる
LIMITATIONS

講師が知っておくべき簡略化

Web通信図HTTP/1.1・HTTP/2でよく見るTCPベースを主例にします。HTTP/3はQUIC/UDPであることを明記しています。
DNS初心者向けに「名前→IP」を中心に扱いますが、DNSにはMX/TXT/CNAME等もあります。
TLSTLS 1.3を概念中心に説明し、古いRSA鍵交換を一般形として使いません。
TCP状態操作図は概念を追う教材です。厳密な実装・タイマー・すべての状態遷移はRFCを参照してください。
ACCESSIBILITY & PRIVACY

配布前の確認

  • 主要操作はボタン・フォーム要素を使い、キーボードフォーカスを表示します。
  • 自動アニメーションは必須ではなく、「次へ」で進められます。端末のprefers-reduced-motionにも配慮します。
  • ログイン・外部トラッキング・受講履歴送信はありません。
  • 実機・組織のアクセシビリティ要件に対する正式な適合監査を意味するものではありません。
