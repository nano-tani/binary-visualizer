HTTPステータスコードは「Requestの結果を伝える3桁」

HTTPステータスコードを初心者向けに解説。1xx〜5xxの分類、200・301・304・401・403・404・429・500・503の意味とブラウザの動きを学べます。

このページで分かればOK

  • ステータスコードがHTTP Responseの結果を示すと分かる
  • 2xx・3xx・4xx・5xxの大分類を説明できる
  • 401/403や500/503など代表コードを区別できる

READ IN 1 MINUTE

1分で読む説明

検索から来た人も、ここだけ読めば要点がつながるように書いています。

クラスで読む

100〜199は情報、200〜299は成功、300〜399はリダイレクション、400〜499はクライアントエラー、500〜599はサーバーエラーのクラスです。

404と500

404 Not Foundは対象リソースが見つからないこと、500 Internal Server Errorはサーバーが予期しない状況に遭遇したことを示します。

401と403

401 UnauthorizedはHTTP認証情報が必要・有効でない状況に使われます。403 ForbiddenはサーバーがRequestを理解しているが処理を拒否する状況です。

304は本文の成功ではない

304 Not Modifiedは条件付きGET/HEADへの応答で、保存済み表現を再利用できることを示します。

COMMON MISUNDERSTANDINGS

よくある勘違い

「404はサーバーが落ちた」サーバーが応答して404を返している場合、少なくともHTTP応答は届いています。
「4xxは全部利用者のミス」Requestに関する問題のクラスですが、UIやAPI設計側に原因があることもあり、責任の断定には使えません。
