IPアドレスを
32ビットで理解する

192.168.1.10のようなIPv4アドレスは、実は32個の0と1です。8ビットずつ4つに分けて10進数に直し、読みやすいように「.」で区切っています。

IPアドレスを分解してみる

数字を直接入力しても、下のビットをタップしても変更できます。各区切りは0〜255です。

192.168.1.10
合計32 bit
byte数4 byte
区切り8 bit × 4
11000000.10101000.00000001.00001010

なぜ1つの数字が0〜255なの？

1区切り = 8 bit8個の0/1で表せる値は、00000000から11111111までです。
11111111 = 255128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255。だから各区切りは最大255です。

IPアドレスの4つの数字は別々のものではなく、1つの32ビット値を8ビットごとに読みやすく区切ったものです。この8ビットの区切りを「オクテット」と呼びます。

よく見るプライベートIP

家庭や社内LANなど、内部ネットワークで使うために予約されているIPv4アドレス範囲です。

10.0.0.0/810.0.0.0 〜 10.255.255.255
172.16.0.0/12172.16.0.0 〜 172.31.255.255
192.168.0.0/16192.168.0.0 〜 192.168.255.255

家のWi-Fiで192.168.x.xをよく見るのは、この範囲がプライベートネットワーク用だからです。
