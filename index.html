COURSE 01

データの基礎

数・文字・容量が、コンピュータの中でどう表されるか。

✓01

2進数は「0と1のスイッチ」と考える

ONになっている桁の値を足す。左へ1桁進むたびに値は2倍になる。

初心者約8分
✓02

16進数は「4 bitを1桁で短く書く」

2進数4 bit = 16進数1桁。0〜9の次はA〜Fで10〜15を表す。

初心者約7分
✓03

bitとbyteは「情報の小ささ」が違う

bitは0/1ひとつ。通常8 bit = 1 byte。byteが集まってKB・MB・GBになる。

初心者約7分
✓04

文字は「番号」と「byte列」に変わる

Unicodeは「文字に番号を割り当てる仕組み」。UTF-8はその番号をbyte列へ符号化する方式。

初心者約9分
✓05

AND・OR・XORは「1 bitずつ比べるルール」

ANDは両方1、ORはどちらか1、XORは2つが違うとき1。

一歩深く約10分
COURSE 02

ネットワークの基礎

PCが通信相手を見つけ、データを届けるまで。

✓01

IPアドレスは「通信相手を指定する番号」

IPv4は0〜255の数字が4つ。内部では8 bit × 4 = 32 bit。

初心者約9分
✓02

CIDRは「32 bitのどこで区切るか」

/24 = 左から24 bitがネットワーク部。残り8 bitがホスト部。

一歩深く約12分
✓03

DHCPは「ネットワーク設定を自動でもらう」

DHCP = IP・ゲートウェイ・DNSなどのネットワーク設定を自動でもらう仕組み。

初心者約9分
✓04

ARPは「このIPのMACアドレスは？」を調べる

同じLANではARPでIPv4→MACを調べる。遠くへ送るときは、まずゲートウェイのMACへ渡す。

一歩深く約10分
✓05

DNSは「名前から通信先を調べる」

DNS = 名前に対応する情報を調べる仕組み。Webでは「名前 → IPアドレス」の名前解決が基本例。

初心者約9分
✓06

ポート番号は「そのコンピュータのどのサービスか」

IP = どのコンピュータ。ポート = そのコンピュータのどの通信サービス。

初心者約8分
✓07

TCPとUDPは「データの届け方」が違う

TCPは信頼性のための仕組みを持つ。UDPはそれをプロトコル自身では持たず、必要ならアプリ側で補う。

初心者約10分
✓08

3-way handshakeは「TCP接続を始める確認」

SYN → SYN-ACK → ACKでTCP接続を確立し、ESTABLISHEDへ進む。

一歩深く約10分
✓09

TCPの正常終了は「片方向ずつ閉じる」

正常終了の基本形はFIN→ACK→FIN→ACK。TIME_WAIT自体は異常を意味しない。

一歩深く約10分
COURSE 03

Webの基礎

ブラウザとサーバーの通信を、HTTPからSessionまでつなげる。

✓01

HTTP / HTTPSは「ブラウザとサーバーの会話ルール」

Webの基本像は「相手を調べる → 通信路を作る → HTTP Request → HTTP Response → 表示」。HTTPSはHTTPをTLSで保護する。

初心者約10分
✓02

TLSは「相手確認・鍵の確立・暗号化」をする

TLSの初心者ゴールは3つ。「相手を確認」「安全に鍵を共有・導出」「その鍵で暗号化と改ざん検知」。

一歩深く約12分
✓03

HTTPメソッドは「このリソースに何をしたいか」を表す

GET=取得、POST=処理/作成、PUT=置換、DELETE=削除が代表例。実際の意味はHTTP仕様とAPI設計に従う。

初心者約10分
✓04

HTTPステータスコードは「Requestの結果を伝える3桁」

2xx=成功、3xx=リダイレクト等、4xx=クライアント側Requestに関する問題、5xx=サーバー側が要求を処理できない。

初心者約10分
✓05

Cookieは「状態の材料」、Cacheは「データの再利用」

Cookie = ブラウザに小さな情報を保存して次のRequestに使える。Cache = 取得済み表現を再利用する。

初心者約12分
✓06

Sessionは「Requestをまたいで利用者の状態を扱う設計」

典型的なSession方式では、ブラウザはセッションIDを持ち、サーバーがそのIDを有効なSessionと照合して利用者状態を判断する。

初心者約12分
TRUST & SCOPE

教材として紹介しやすくするために

標準資料へのリンクTCP・HTTP・TLS・DNSなどはRFCやIANA等の参考資料を各ページに掲載。初心者向けに省略した範囲も明示します。

配布しやすいURLログイン不要。各テーマのURLを単独で共有でき、印刷・投影モードも使えます。
