AND・OR・XORを
触って理解する

まず1ビットで違いをつかんで、そのあと8ビットで結果を確認します。

まず1ビットで見る

AとBをタップして0/1を切り替えてみてください。

AND：AとBが両方とも1のときだけ1になります。
結果0
0 AND 0 = 0
0 と 00
0 と 10
1 と 00
1 と 11

AND：両方1なら1

OR：どちらか1なら1

XOR：違えば1。同じなら0

つぎに8ビットで見る

AとBの各ビットをタップすると、同じ演算を8桁まとめて確認できます。

A170 / AA
B204 / CC
結果136 / 88
10進数136
2進数10001000
16進数88

3つの違い

AND は必要なビットだけ残したいとき、OR は特定のビットを1にしたいとき、XOR は違いを見つけたり反転したいときによく使います。

10101010 AND 11001100 = 10001000
