AND・OR・XORを
触って理解する

ビット演算は、2つの0と1をルールに沿って比較する処理です。まずは1ビットをロジック図形で見て、そのあと8ビットでも確認してみてください。

まず1ビットをロジック図形で見る

AとBを押すと入力が変わり、ロジックゲートを通った結果がすぐに変わります。

入力A入力B出力
0 AND 0 = 0
0 と 00
0 と 10
1 と 00
1 と 11
AND両方が1のときだけ1になります。
ORどちらかが1なら1になります。
XOR違うときだけ1になります。同じなら0です。

つぎに8ビットで見る

AとBの8ビットはタップで0/1を切り替えられます。選んだ演算の結果がその場で変わります。

A170 / AA
B204 / CC
結果136 / 88
10進数136
2進数10001000
16進数88

よくある勘違い

AND・OR・XORは、数全体をまとめて比べるのではなく、同じ位置のビット同士を1桁ずつ比較します。左端から右端まで同じルールを8回適用しているだけです。

10101010 AND 11001100 = 10001000
