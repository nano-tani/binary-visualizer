IPv4は32ビットです。そのうち左から何ビットをネットワーク部に使うかを表すのがCIDRです。ビットを直接タップして、/24 や 255.255.255.0 の意味を手で確認できます。

IPとマスクを触ってみる

マスクのビットを直接タップしてください。1を押すとそこまでがネットワーク部になり、0を押すとそこから右がホスト部になります。

なぜ /24 = 255.255.255.0 なの？

ここも同じです。ビットを押すと 1 と 0 が切り替わり、CIDR と 10進数表記が連動します。

説明用の32ビットマスク

1を押すとそこまで1になります。0を押すとそこから右が0になります。サブネットマスクなので、途中で 1 と 0 が混ざらない形に固定しています。

サブネットマスクの 1 は「ここはネットワーク部」、0 は「ここはホスト部」 という印です。IPアドレスとサブネットマスクを AND演算 するとネットワークアドレスが求められます。

ホスト部のbit数で台数が決まる

ホスト部が n bit あると、アドレス総数は 2ⁿ 個です。ただし普通のネットワークでは、先頭のネットワークアドレスと末尾のブロードキャストアドレスは使えないので、利用可能IP数は通常 2ⁿ - 2 になります。/31 と /32 は特殊です。

/24 ならホスト部は8 bit。総アドレス数は256、利用可能IPは254です。
